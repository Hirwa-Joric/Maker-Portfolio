# Illustrations of the completed console

These views show how my console fits together: its shape, layers, light path and installed wiring. Photographs, measurements and a scan support checks against the physical panel. See the [development sequence](../README.md#from-design-to-build) for the design, build and documentation stages.

The exploded arrangement illustrates the structure. The wiring drawing uses dashed connections where the photographs do not establish the route. It documents the installed arrangement, with those limits; it is not an upgraded circuit.
