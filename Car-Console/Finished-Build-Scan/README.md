# Scan of the finished console

This scan records the finished console I began building in January 2026. Captured on 3 October 2026, it supports measurements of the finished panel and comparisons with the explanatory model.

These scan files belong to the later documentation stage. The current model in `../3d/` illustrates the completed design; the scan lets it be compared with the physical object.

`scan_01_12-45.glb` is the source scan. The aligned GLB/STL files put that scan into the presentation model's coordinates. `scan-measurements.json`, `SCAN-NOTES.md` and `views/` record checks of the finished object.
